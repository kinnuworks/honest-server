Check your own server

The table above checks from our machine, over Tor. To test what your server sends to you, run the check on your own computer. It talks only to your server and to Zcash peers, and sends nothing to us.

cargo install --git https://github.com/kinnuworks/honest-server
honest-server check zec.rocks:443
honest-server check zec.rocks:443 --test-drop-note

Protect your wallet

Run a light-wallet server on your own machine and point your wallet at it. It forwards every call to the real server over Tor when Tor is running, so the server sees a Tor exit instead of your IP. It checks every recent block, and a random sample of older ones, against verified blocks from Zcash peers, and refuses any block that doesn't match.

honest-server proxy zec.rocks:443
# then set your wallet's server to http://127.0.0.1:9067

How it works

  1. It reads the server's info, its latest block and a range of recent blocks, the same calls a wallet makes when it syncs.
  2. It fetches the same blocks from Zcash peer-to-peer nodes and checks each one: Equihash proof of work, the difficulty target, the merkle root over the transaction IDs and the height in the coinbase. Two peers have to serve the same block.
  3. It compares every Sapling spend and output and every Orchard and Ironwood action, by transaction and position: nullifiers, note commitments, ephemeral keys and the first 52 bytes of each ciphertext.
  4. It walks the peers' headers forward from the server's last block to see whether the server is behind or on a fork, and reads which node release the server runs.

What it can't see

It checks a window of recent blocks, not the whole chain. It can't see what a server logs about the wallets that connect to it, and it doesn't test transaction submission. When it can't reach a server or two peers can't confirm a block, it says "couldn't verify" and doesn't count that as a failure.

Zebra 6.4 nodes stop at block 3,540,768. NU7 activates at block 3,543,405. Servers whose node isn't upgraded will stop or fork off around then.
